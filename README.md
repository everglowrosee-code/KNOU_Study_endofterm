# 캡틴의 시험노트 — 프로젝트 소개

기출과 강의자료를 연결해, 답의 근거까지 이해하는 기말시험 학습 도구.

기준일: 2026년 10월 30일

## 무엇을 위한 프로젝트인가요?

캡틴의 시험노트는 방송통신대학교의 기출문제와 강의자료를 연결해 기말시험을 준비하는 학습 웹사이트입니다. 공부 자료를 찾고, 문제를 풀고, 답의 근거를 확인하는 과정을 한곳에 모았습니다.

여러 시험에서 반복된 개념을 우선 복습하면서, 기존 기출만으로 충분히 다루지 못하는 강의 내용도 함께 준비하는 것이 목표입니다. 프로그래밍 언어론은 1~15강 전체를 다루며, 프랑스어회화2는 제공된 2017~2019년 기출 3회분을 다룹니다.

## 현재 사용할 수 있는 기능

| 기능 | 현재 제공 내용 |
| --- | --- |
| 과목별 기출 | 프로그래밍 언어론 시험 6회, 원문 155문항. 시험 종류별로 고르고 PDF·코드·도표를 보며 답안을 작성합니다. |
| 프랑스어회화2 | 2017·2018·2019년 기말 3회, 총 105문항. 문제지 36~70번에 정답표 1~35번을 연결했습니다. 원문 PDF·정답표, 문항별 해설, 반복 개념 22개, 채점과 오답 노트를 제공합니다. |
| 자료구조 | 2017·2018·2019년 기말·대체시험 6회, 총 120문항. 기말 36~60번, 대체 16~30번을 정답표에 연결했습니다. 원문 PDF·정답표, 해설, 반복 개념 14개, 채점과 오답 노트를 제공합니다. K는 모든 보기, F는 ③·④ 정답입니다. 강의자료와 예상문제는 아직 등록되지 않았습니다. |
| 컴퓨터과학개론 | 기출 6회·150문항 전체 채점과 2017년 기말 수정 정답표 반영. 1~15강 PDF, 기출 확장 보충 15개, 예상문제 45개(기출 변형 30·강의 보충 15)를 제공합니다. 4강은 2025.09.10 수정본이며 개정 전후 변경 범위는 확인하지 않았습니다. |
| 오픈소스 기반 데이터분석 | 기출 없이 1~15강 PDF 279쪽을 바탕으로 강의별 노트와 자체 제작 예상문제 45개를 제공합니다. 기출·반복 출제 목록에서는 제외하고 예상문제·강의 노트에서 선택합니다. 각 문제에 보기별 해설과 근거 페이지를 연결합니다. |
| 예상문제 | 프로그래밍 언어론·컴퓨터과학개론·오픈소스 기반 데이터분석에 각 45문항. 기출 변형 60문항, 강의 보충 30문항, 기출 없는 강의 기반 45문항을 제공합니다. 과목별 회차와 오답은 분리 저장합니다. |
| 즉시 피드백 | 예상문제의 보기를 선택하면 정답·오답, 정답 해설, 보기별 이유를 바로 확인합니다. 기출시험은 답안을 작성한 뒤 채점합니다. |
| 출처 확인 | 강의 PDF의 근거 페이지, 추출 원문 또는 원문 대조 요약을 확인합니다. 관련 기출이 있으면 해당 문항으로 이동합니다. |
| 반복 출제 | 여러 시험에서 반복되는 개념을 16개 문항군으로 모아 검색하고 관련 기출을 확인합니다. |
| 강의 보충 | 프로그래밍 언어론·컴퓨터과학개론·오픈소스 기반 데이터분석의 각 15강 PDF를 제공합니다. 기출 없는 과목은 강의 노트로 표시합니다. 컴퓨터과학개론은 보충 개념 15개의 요약·근거 페이지·바로 풀기와 주의할 강의 설명을 먼저 보여줍니다. |
| 오답 노트 | 기출 오답·미응답과 예상문제 오답을 모아 복습합니다. 예상문제는 다시 풀어 맞히면 오답 목록에서 빠집니다. |
| 이어 풀기 | 답안과 진행 상황을 사용 중인 브라우저에 저장합니다. |

## 이렇게 공부하면 됩니다

1. 기출이 있는 과목은 과목별 기출에서 시작합니다. 기출 없는 오픈소스 기반 데이터분석은 예상문제 또는 강의 노트에서 선택합니다.
2. 반복 출제 화면에서 같은 개념이 다른 시험에 어떻게 등장했는지 비교합니다.
3. 예상문제에서 원하는 강의와 문항 수를 골라 회차를 시작합니다. 기출 없는 과목은 강의 기반 문제로만 구성됩니다.
4. 보기를 고른 뒤 정답과 보기별 설명을 읽고, 강의 PDF의 해당 페이지로 근거를 확인합니다.
5. 오답 노트에서 놓친 개념을 다시 풀고 필요한 강의를 복습합니다.

## 예상문제는 어떻게 만들고 출제하나요?

기출 변형 문제는 제공된 시험에서 반복된 개념과 질문 방식을 바탕으로 작성했습니다. 예를 들어 같은 개념을 다른 수치나 코드, 보기로 바꾸어 답의 번호보다 원리를 이해하도록 구성합니다.

강의 보충 문제는 현재 제공된 1~15강에서 확인한 핵심 내용을 바탕으로 작성했습니다. 형식 의미론, 이름 공간, 단축 평가, 코루틴, 다형성처럼 제공 기출만으로 충분히 연습하기 어려운 내용도 포함합니다.

현재는 미리 작성한 135문항의 문제은행에서 범위에 맞는 문제를 뽑고, 문제 순서와 보기 순서를 섞어 회차를 구성합니다. 접속할 때마다 AI가 새로운 문장을 실시간으로 생성하는 기능은 아직 없습니다.

예상문제에는 정답, 전체 해설, 네 보기의 설명, 강의 번호·PDF 페이지·추출 원문 또는 대조 요약을 연결합니다. 관련 기출이 있는 문제에는 시험 연도와 문항 번호도 붙입니다. 첫 선택을 채점 결과로 저장하고, 같은 회차에서 다른 보기로 바꿔 정답 처리하지 않습니다.

## 자료를 읽는 기준

프랑스어회화2의 2018년 41번(정답표 6번)은 사용자 정답표의 K에 따라 ①~④ 어느 보기를 선택해도 정답입니다. 미응답은 오답으로 표시합니다. 이 채점 처리는 모든 보기가 문법적으로 맞다는 뜻은 아닙니다. 이 과목의 강의노트와 예상문제는 아직 등록되지 않았습니다.

- 기출 정답은 사용자가 제공한 정답표를 우선합니다. 해설은 강의의 정의와 문제에 제시된 조건에 맞춰 읽습니다.
- 반복 횟수는 각 과목에 제공된 시험 안에서의 출현입니다. 프로그래밍 언어론 6회, 프랑스어회화2 3회, 자료구조 6회, 컴퓨터과학개론 6회이며, 같은 개념의 변형 문제도 포함합니다. 올해 출제 확률을 뜻하지 않습니다.
- ‘강의 보충’은 제공 기출만으로 충분히 다루지 못한 내용입니다. 과거 강의판과 비교해 새로 추가되거나 개정됐다고 확인한 표시는 아닙니다.
- 근거에 표시한 PDF 페이지는 파일의 첫 장부터 센 번호입니다. 강의 슬라이드에 인쇄된 번호와 다를 수 있습니다.
- 과거 기출의 용어와 현재 강의의 표현이 다르거나 문제의 가정에 확인이 필요한 경우에는 별도로 표시합니다.

## 풀이 기록은 어디에 저장되나요?

답안, 진행 상황, 예상문제의 오답 기록은 브라우저의 로컬 저장소에 보관됩니다. 같은 브라우저에서 이어 풀 수 있지만 다른 기기·브라우저·접속 주소와 자동으로 동기화되지는 않습니다. 브라우저 데이터를 삭제하면 기록도 지워질 수 있습니다.

문제와 강의자료는 사이트에 포함된 파일로 제공됩니다. 현재 사이트에는 사용자가 직접 자료를 업로드하거나 문제를 자동으로 생성하는 서버 기능이 없습니다. 자료나 문항을 바꾸려면 사이트의 파일을 수정해 다시 게시합니다.

## 프로젝트는 어떻게 구성되어 있나요?

HTML·CSS·JavaScript로 만든 정적 웹사이트입니다. 별도 설치나 빌드 없이 파일을 웹 서버에서 제공할 수 있고, 파일 경로를 상대 경로로 연결해 GitHub Pages의 프로젝트 주소에서도 사용할 수 있도록 구성했습니다.

| 파일·폴더 | 역할 |
| --- | --- |
| index.html | 사이트의 기본 화면과 학습 메뉴 |
| about.html / PROJECT.md | 이 프로젝트 설명의 웹 페이지와 Markdown 문서 |
| styles.css / quiz.css / about.css | 기본 화면, 예상문제 화면, 프로젝트 소개 화면의 디자인 |
| app.js | 기출 목록, 답안 작성, 채점, 반복 출제, 강의 및 오답 화면 |
| quiz.js | 예상문제 회차 구성, 즉시 채점, 이어 풀기와 오답 재풀이 |
| data.js / data.json | 기출 정답·해설, 강의 목록, 반복 출제 및 보충 주제 데이터 |
| courses.js / french-data.json | 과목 선택 목록과 프랑스어회화2 기출·정답·해설 데이터 |
| ds-data.js / ds-data.json | 자료구조 기출·정답·복수정답·해설 데이터 |
| cs-data.js / cs-data.json | 컴퓨터과학개론 기출·강의 보충·복수정답 데이터 |
| predictions.js / cs-predictions.js | 과목별 예상문제, 보기별 설명, 강의 근거 데이터 |
| assets/ | 시험 원문 이미지, 기출 PDF와 강의 PDF |

Sites와 GitHub 저장소는 각각 별도로 관리됩니다. 한쪽의 파일을 바꾸면 다른 쪽에도 반영해야 합니다. 접속 제한은 호스팅 서비스의 설정을 따르며, GitHub Pages로 옮겼을 때 기존 Sites의 ChatGPT 로그인 보호가 자동으로 따라가지는 않습니다.

## 앞으로 확장하고 싶은 방향

다른 과목의 기출과 강의자료를 추가하고, 검토한 예상문제의 수와 다양성을 늘리는 것이 다음 방향입니다. 더 최근의 기출과 개정 전후 강의자료가 확보되면 출제 경향과 변경 내용을 더 정확히 비교할 수 있습니다.

처음 구상한 독서·학습 내용 요약, 할 일 관리와 업데이트 스킬도 후속 확장 후보입니다. 기기 간 풀이 기록 동기화, 사이트 내 자료 업로드, 실시간 AI 문제 생성 역시 향후 검토할 기능이며 현재 구현된 기능은 아닙니다.

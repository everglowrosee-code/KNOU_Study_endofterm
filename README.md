# 캡틴의 시험노트

방송통신대학교 과목별 기출과 예상문제를 풀어보는 개인 학습 사이트입니다. 현재 프로그래밍 언어론 자료를 수록했습니다.

- 기출시험 6회, 총 155문항과 정답·학습 해설
- 기출 변형 30문항과 강의 보충 15문항으로 구성한 예상문제
- 예상문제 선택 즉시 정오답 판정, 보기별 이유와 강의 PDF 근거 페이지 표시
- 강의 범위·출제 유형·문항 수 선택, 문제와 보기 순서 섞기
- 반복 출제 주제, 1~15강 PDF, 오답 노트와 이어 풀기

## 실행

`index.html`을 열거나 저장소 전체를 정적 웹 서버에서 제공하면 됩니다. 별도 설치나 빌드가 필요하지 않습니다. 파일을 옮길 때는 `assets/`를 포함한 전체 파일을 함께 유지하세요.

답안과 오답은 각 브라우저의 로컬 저장소에 저장되며 기기 간에 동기화되지 않습니다. 예상문제는 자료를 바탕으로 미리 작성한 45문항에서 매회 조합하며 접속 중 AI가 새 문항을 생성하는 방식은 아닙니다.

## GitHub Pages

저장소의 **Settings → Pages → Deploy from a branch**에서 `main` 브랜치와 `/ (root)`를 선택하면 게시할 수 있습니다. 모든 파일 경로는 상대 경로여서 프로젝트 경로에서도 사용할 수 있습니다.

이 저장소는 기존 Sites 사이트의 복사본입니다. 어느 한쪽을 수정해도 다른 쪽에 자동으로 반영되지 않습니다. GitHub Pages에는 기존 Sites의 ChatGPT 로그인 보호가 적용되지 않습니다.

‘강의 보충’은 제공된 기출만으로 충분히 다루지 못한 내용이며 과거 강의와 비교해 개정이 확인됐다는 의미는 아닙니다. 예상문제는 실제 출제를 보장하지 않습니다.
